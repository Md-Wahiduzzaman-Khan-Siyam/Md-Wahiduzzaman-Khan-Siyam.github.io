# Portfolio

Static site (HTML/CSS/JS, no build step). Hosted with GitHub Pages.

## Deploy
1. Create a GitHub repo named `Md-Wahiduzzaman-Khan-Siyam.github.io` (public).
2. Upload everything in this folder to the repo root (`index.html`, `assets/`, `Md. Wahiduzzaman Khan Siyam.pdf`).
3. Repo Settings > Pages > Deploy from branch > `main` / root.
4. Your site will be live at https://md-wahiduzzaman-khan-siyam.github.io
